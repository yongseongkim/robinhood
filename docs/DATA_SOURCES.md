# 데이터 출처와 수집본 기록

서비스가 사용하는 출처 개요는 [루트 README](../README.md)에 있습니다. 아래 건수와 검증 결과는 기존 README에 기록된 2026-10-21 수집본의 스냅샷입니다. 최신 수집 시각과 자료 범위는 서비스의 출처 화면에서 확인합니다.

출처별 URL과 조사 기록은 [data-sources.json](data-sources.json), 기관별 수집과 지원 범위는 실제 `pipeline/` 수집기와 [서버 안내](../robinhood-server/README.md)를 참고하세요.

직책 보유자(의장단·상임위원장, 기수별)는 각 의회 공식 홈페이지의 선출 기록에서 수집해 연결했습니다.
서울 구의회 23곳은 `pipeline/districts/g1~g3.py`가 2022-07(제9대)부터 수집하며, 수집된 의회는 `data/staging/councils/<slug>.json`으로 자동 등록됩니다. 강북구의회 재수집에는 Playwright와 Chrome이 필요합니다(서버가 스크립트 요청을 막음). 스캔·이미지 PDF(강남·강동·용산·중랑·서울시의회 일부, 2022년 이후 117개)는 `pipeline/parse_ocr.py`가 macOS Vision OCR로 읽어 5,600여 행을 추가합니다(이 컴퓨터 안에서 처리, 외부 전송 없음). 인쇄된 합계가 있는 40개 파일 중 21개가 원 단위까지 일치했고(서울시의회 5/5, 용산 15/17), 강동은 읽은 합계가 인쇄 합계의 중앙값 97.7%입니다. OCR 행에는 "스캔본 OCR로 읽음" 표시가 붙고, 합계가 일치한 파일만 신뢰도 "보통", 나머지는 "낮음"입니다. OCR 결과 캐시는 `data/ocr/`에 저장됩니다.

"우리 동네" 지도(`#/region`)는 제22대 국회의원 지역구 254곳과 서울 25개 구를 그립니다. 경계: 통계청 SGIS 행정동 경계(공공누리 제1유형)를 vuski/admdongkor가 가공한 자료(CC BY 4.0), 선거구: 오마이뉴스 2024_22_elec_map(MIT). `pipeline/build_geo.py`가 미리 투영한 SVG 경로와 시·군·구 인접 정보를 `site/data/geo.js`로 만들고, 인접 정보는 "관할·인접 지역 밖 사용" 규칙에도 쓰입니다.

원본 수록 지출 433,172건 중 서로 다른 공개 파일에 다시 실린 같은 거래 670건을 빼고 432,502건을 분석합니다. 탐지 규칙 28개, 탐지 결과 4,705건.

열린국회정보: 의원 인적사항은 정당·지역구·위원회·당선 횟수 등 공적 정보만 저장하고 생년월일·전화·이메일·보좌진·약력은 받지 않습니다. 정치자금 자료의 의원과는 이름+지역구로 연결합니다. 현직 20명은 정치자금 자료(2023~2024년) 이후 재보궐·승계로 들어와 연결할 자료가 없습니다. 동명이인은 표결 기록의 정당이 한결같고 같은 이름·정당이 한 명뿐일 때만 나누고(제21대 김병욱 두 명), 그래도 구분되지 않으면 연결하지 않고 개수만 셉니다. 이미 연결된 의원에 다른 의원 코드를 이름만으로 붙이지 않습니다(2026년 보궐로 들어온 동명이인 박지원). 표결은 `collect_votes.py`가 처리된 의안마다 1회씩(1초 간격) 받아 쌓고, 다시 실행하면 새로 처리된 의안만 받습니다.

재산: 국회공보 PDF(893쪽)를 직접 읽고, 의원마다 항목 합계 = 소계, 소계 합계 - 채무 = 총계인지 확인합니다(287명 전원 통과). 정보공개센터가 정제한 스프레드시트와 총계·부동산 항목을 대조해 모두 일치했습니다. 정보공개센터 자료는 CC BY-NC-ND라 검증에만 쓰고 사이트에는 싣지 않습니다. 부동산 위치는 시·군·구와 읍·면·동까지만 싣고 지번·건물명·동호수는 저장하지 않습니다. 금액은 신고가액(공시가격 등)이라 시세와 다를 수 있고, 고지거부한 부모·자녀 재산은 빠집니다.

열린재정: 금액은 모두 원 단위로 바꿔 저장합니다(원자료 단위는 조원·억원·천원이 섞여 있음). 해마다의 총수입·총지출은 12월 누계가 있는 연도만 결산 값으로 씁니다. 예산(본예산·국회확정)과 결산은 섞지 않고 화면에 어느 쪽인지 적습니다. 규칙 명세는 사이트의 "탐지 규칙" 페이지와 `pipeline/rules.py`에 있습니다.

세부사업 예산은 현재 연도 기준 과거 4년부터 다음 연도까지 수집하고, 연도별 국회 확정액과 정부안을 각각 보존합니다. 분야·부처 비중의 분모는 같은 통계·연도의 수록 항목 합계입니다. ‘수집 부처 예산 합계’는 세부사업의 국회 확정액 또는 정부안 합계로, 결산 총지출이나 별도 정책 묶음(예: 청년 지원 예산)과 동일한 통계로 간주하지 않습니다. 분야는 공식 코드를 우선 연결하고 부처는 같은 이름의 항목을 비교하므로, 조직 개편으로 이름이 달라지면 전년 값이 없을 수 있습니다.

## 자료 해석 원칙

- 탐지 결과는 추가 확인이 필요한 패턴이지 위반·부정의 증거가 아닙니다. 법령 기준 대조 / 통계 기준 / 같은 값 반복 / 단어 일치 / 공개자료 점검을 구분해 표시합니다.
- 탐지 결과로 지출 주체에 점수를 매기지 않습니다. 순위판은 공개된 금액·건수를 같은 재원·같은 기간 안에서 그대로 줄 세운 것이고, 판단은 보는 사람에게 맡깁니다.
- 재원(정치자금, 의회운영업무추진비, 의정운영공통경비, 사무국 업무추진비)은 서로 합산하지 않습니다.
- 공동경비를 의원 개인 지출로 귀속하지 않습니다. 직책 업무추진비에는 그 기간의 직책 보유자를 의회 홈페이지 기준으로 표시하되, 개인 지출로 표시하지 않습니다.
- 모든 탐지 결과 → 근거 거래 → 원본 문서(URL, sha256)까지 추적됩니다.
- 생년월일·개인 주소·전화번호·후원인 정보는 게시하지 않고, 개인에게 지급된 금액의 사용처는 "개인(비공개)"로 바꿉니다.
